name: pdf
description: Read, inspect, create, edit, merge, and extract text or tables from PDF documents using command-line tools. Use when working with PDF files.
---

Use command-line tools to read, inspect, create, and edit PDF documents. Do not use the agent's tool calling directly to read PDFs.

If a required tool is not installed, ask the user whether they want to install it. Do not install tools without the user's permission.
