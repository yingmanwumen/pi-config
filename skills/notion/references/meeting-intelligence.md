# Meeting Intelligence

Use this workflow to prepare agendas, pre-reads, decision meetings, planning sessions, retrospectives, 1:1s, or brainstorming sessions.

1. Confirm goal, attendees, date/time, duration, decisions needed, and desired outcomes.
2. Search and fetch prior notes, specs, OKRs, decisions, risks, and action items.
3. Choose a format: status update, decision, planning, retrospective, 1:1, or brainstorming.
4. Draft context, goals, agenda, owner and timebox for each item, pre-reading, risks, and expected outputs.
5. Include direct links to source pages and separate supplemental research facts from recommendations.
6. Confirm the destination parent before creating the page; create it with `POST /v1/pages` and block children as needed.
7. Re-fetch the page and report follow-ups, owners, and open questions.

Create or update task records only when the user authorizes it and the target database schema is known.
